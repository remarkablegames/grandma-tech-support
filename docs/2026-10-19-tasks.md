# Tasks

Companion spec to [Grandma Tech Support](./2026-10-18-grandma-tech-support.md): the
eight-task chain that structures a full playthrough.

The game is no longer a single find-the-email vignette. A playthrough is a chain of
eight tasks on one desktop: each completion opens a Win95 dialog with `Next task`, and
the eighth opens the final `Computer saved!` screen with `Play again`. The desktop
starts blank and the chain fills it: task 4 is the first ad storm, task 7 floods
every window at once, and each storm after that reopens whatever the player closed.
Icon windows, the login, and per-window state persist between tasks.

- **Completion events.** `completeObjective(event)` matches the event against the
  current entry of `OBJECTIVES`. No match means nothing happens, so the Shut Down
  dialog, decoy clicks, and early scans stay harmless. The wrong click at the wrong
  time is never a lose state.
- **Spring-back.** A task's config can carry `open` (windows that spring open when it
  starts), and every `spawn` entry reopens its target window, so storms always land
  visible, even on a desktop the player tidied up between tasks. A task can also carry
  `clingy: ['shopping']`: the sale page's `×` refuses the first two closes, answering
  with a joke and a fresh pop-up each time, the way adware pages did — only the third
  close takes, and End Task always bypasses it.
- **Inbox cleanout.** Task 3 turns the Inbox into a real mail client: rows select on a
  click, open on a double-click, and Delete (toolbar button or the Delete key) removes
  the selected row, handing selection to the next one. The junk breeds two more rows
  per read, capped at four extra rows for the evening, so reading is the trap and the
  sweep is the lesson. The grandkids' email can't be deleted. The window title counts
  its mail live.
- **Update dialog.** A task with `update: true` opens the UpdateDialog when it starts;
  its stages advance only on clicks (`installing` → `restored` → `failed`).
  `Restart now` sets the power screen to `boot` without `playAgain()` and queues
  `update-rebooted`; `leavePowerScreen` fires the queued completion when the clouds
  lift and the desktop comes back with everything intact.
- **Disk-full task.** A task with `lowDisk: true` raises the low-disk System Message
  (red X, error ding) when it starts, the way `update: true` opens the UpdateDialog —
  grandma clicked Toaster Setup and Drive C: has 4 bytes left. Its two culprits
  (`TASK_FILES`: `toaster_8_install.exe` and `toasters_the_movie.avi`) land at the
  top of the desktop's second column for the task alone: the layout store never learns
  their ids, so they arrive fresh and in place every time, drag and drop like any
  shortcut, and double-clicking one re-raises the error it came from.
  `noteDiskMilestone('binned' | 'emptied')` puts grandma's next beat in the speech
  bubble — never a dialog, never a completion — only while the task is current:
  both files in the bin, then the bin emptied for real.
- **Empty Recycle Bin.** The bin's icon menu carries Win95's extra entry, greyed while
  the bin sits empty (it starts with nothing in it, Win95 style, and every row it ever
  lists is a real, restorable shortcut). Picking it opens a `Confirm Delete`
  dialog (Yes autofocused, No cancels); Yes moves everything in the bin to a persisted
  `deleted` list — emptied means deleted for the evening: those icons stay off the
  desktop (the culprits included), while filed shortcuts stay in My Documents. The
  entry ships always available, not task-locked.
- **Menu Delete.** Every icon and row menu's `Delete` is Win95's own wherever the
  bin will take the file: one `Confirm Delete` (the file named, its face
  looking on), and `Yes` recycles it exactly like the drop — the same `drop`
  tick, the same full bin face, and the `binned` beat counts menu-recycled
  culprits too, so the task never demands the drag idiom. From inside the bin a
  row's `Delete` asks the other question (`delete ‘the file’?`) and moves just
  that file to the `deleted` list for real — a second route to a deleted-for-real
  evening whose `emptied` chatter stays tied to the empty's wipe. System icons
  (My Computer, the bin, My Documents) and scenery rows keep the joke `Delete`,
  where it is literally true; `Properties` stays a joke everywhere.
- **Disk Defragmenter.** Start → Programs → `Disk Defragmenter` opens the drive tool
  any evening: a deterministic block grid consolidating left to right while the
  percentage climbs 1% per 100ms (about ten seconds). `Stop` freezes the run with a
  joke; `Exit` closes it — at 100% it completes `defrag-done` (the finale's only
  completion), earlier it jokes and lets the player come back. Defragmenting on any
  other task is harmless.
- **Virus Shield's Programs twin.** Start → Programs → `Virus Shield` (above the
  defragmenter) opens the task-6 scanner exactly like the desktop icon, so the task
  stays winnable after the player recycles that shortcut and empties the bin for real.
  The task copy still teaches the desktop route.
- **Frozen windows.** `freeze: [...]` marks windows dead: raises and taskbar toggles
  no-op, chrome buttons lose their handlers, dragging stops, and the title bar shows
  `(Not responding)` (the one knowingly post-Win95 borrow, for readability). Clicking
  anywhere on the frame just swaps Grandma’s line for the diagnosis. `End Task` from
  the Task Manager list clears the flag, closes the window, and completes the task.
- **The chord stays a secret.** Real Win95 opened Close Program with Ctrl+Alt+Del and
  no Start-menu entry, and Windows swallows the chord before any browser sees it. The
  game listens anyway where the browser receives it (macOS/Linux keydown; jsdom
  always delivers, unlike Windows), but the task never depends on it — Start →
  `Task Manager` is the guaranteed mouse route, and the dialog’s own `Shut Down` runs
  the real shutdown flow.
- **Login gate.** The inbox window shows a log-on form until `login()` succeeds with
  the password from the note; wrong guesses show an inline alert (Grandma’s hint),
  never a lose state. The gate stays open for the rest of the playthrough.
- **Task recall.** Reactions overwrite Grandma’s line, so clicking her speech
  bubble puts the current task’s instruction back (the bubble is a real button;
  screen readers get an `sr-only` hint). Start → `Help` shows the same
  instruction in a System Message with the ℹ️ info face and no error ding.
- **Dialogs.** Task screens and the final screen are the same prop-driven WinScreen
  (title, message, icon, and button label come from the current objective): `Next task`
  for tasks 1 through 7, `Play again` on the eighth. Every one plays the `win`
  jingle.
- **Reset.** `Play again` returns to the blank opening (windows closed, no pop-ups)
  and resets the objective index, login, the ad-storm flag, the update dialog, the
  defragmenter, and any frozen windows, plus everything the base game already resets —
  and in the desktop layout it brings back everything emptied
  for real. The same
  reset runs mid-game behind Start → `Shut Down...` → `Restart the computer?` — the
  boot line, then the clouds splash — so the player can start over without winning
  first — see [shutdown](./2026-10-20-shutdown-restart.md). The update’s own reboot
  is the opposite: it keeps the whole evening in place.
- **Out of scope.** Level select, saved progress, per-stage desktops (`OBJECTIVES` is
  shaped so distinct scenes can come later), timers, difficulty modes.
