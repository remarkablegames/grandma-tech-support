# Missions

Companion spec to [Grandma Tech Support](./2026-10-18-grandma-tech-support.md): the
six-task mission chain that structures a full playthrough.

The game is no longer a single find-the-email vignette. A playthrough is a chain of
six tasks on one desktop: each completion opens a Win95 dialog with `Next task`, and
the sixth opens the final `Computer saved!` screen with `Play again`. The desktop
starts blank and the chain fills it: task 2 springs every browser window back open
with its pop-up chaos, and each storm after that reopens whatever the player closed.
Icon windows, the login, and per-window state persist between tasks.

| #   | Task                         | What the player does                                                                                                                                                                                                                                                 | Completes on      | Escalation                                                                                                 |
| --- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | ---------------------------------------------------------------------------------------------------------- |
| 1   | **Log in**                   | Sticky Notes says the password is on “the other note”; open `My Documents`, double-click `the_other_note.txt` (Notepad window), launch the Inbox from the Start menu, type `password` into the log-on form                                                           | `logged-in`       | teaches icon windows, Start-menu launchers, file rows, and the login gate (no pop-ups yet)                 |
| 2   | **Find the email**           | the original game’s win, moved to slot two: the whole desktop springs open (Shopping, Virus, Inbox) with the deal, spam, and mailbox-full pop-ups; dismiss `full` with `×`, open the real email from the grandkids among phishing decoys                             | `email-opened`    | task start opens all three windows and lands `deal` + two `spam` in Shopping, `full` in the Inbox          |
| 3   | **Order the toaster**        | the first product click tells the joke and starts an ad storm; clear the sale page’s pop-ups with `×` (or shut the window, which takes them along) and click a product again; the other windows’ storms don’t block the order                                        | `order-placed`    | the storm springs all three windows back open (capped at 5 pop-ups per window)                             |
| 4   | **Windows Update**           | grandma clicked something; a Windows Update dialog takes over. The progress bar sticks at 99%, `Cancel` triggers the rollback gag, `OK` admits nothing was restored, and the failure offers `Later` (a liar — its joke lands and the dialog stays) and `Restart now` | `update-rebooted` | click-driven only — no timers; the reboot is mission-preserving, unlike Start → `Shut Down...` → `Restart` |
| 5   | **End Task the frozen page** | the bargain page springs open frozen: `(Not responding)` title, gray title bar, wait cursor, every click dead except grandma’s diagnosis. Open Start → `Task Manager`, select the frozen entry, hit `End Task`; End Task on a healthy window is a harmless joke      | `frozen-ended`    | teaches the Task Manager dialog; End Task kills the window for real, pop-ups and all                       |
| 6   | **Save the computer**        | grandma clicked one more thing; spam floods every window, liar `Close` buttons keep spawning more. Open the `Virus Shield` desktop icon and run a scan                                                                                                               | `scan-complete`   | the scan sweeps the whole storm in one motion                                                              |

- **Completion events.** `completeObjective(event)` matches the event against the
  current entry of `OBJECTIVES`. No match means nothing happens, so the Shut Down
  dialog, decoy clicks, and early scans stay harmless. The wrong click at the wrong
  time is never a lose state.
- **Spring-back.** A task's config can carry `open` (windows that spring open when it
  starts), and every `spawn` entry reopens its target window, so storms always land
  visible, even on a desktop the player tidied up between tasks.
- **Update dialog.** A task with `update: true` opens the UpdateDialog when it starts;
  its stages advance only on clicks (`installing` → `restored` → `failed`).
  `Restart now` sets the power screen to `boot` without `playAgain()` and queues
  `update-rebooted`; `leavePowerScreen` fires the queued completion when the clouds
  lift and the desktop comes back with everything intact.
- **Frozen windows.** `freeze: [...]` marks windows dead: raises and taskbar toggles
  no-op, chrome buttons lose their handlers, dragging stops, and the title bar shows
  `(Not responding)` (the one knowingly post-Win95 borrow, for readability). Clicking
  anywhere on the frame just swaps Grandma’s line for the diagnosis. `End Task` from
  the Task Manager list clears the flag, closes the window, and completes the task.
- **The chord stays a secret.** Real Win95 opened Close Program with Ctrl+Alt+Del and
  no Start-menu entry, and Windows swallows the chord before any browser sees it. The
  game listens anyway where the browser receives it (macOS/Linux keydown; jsdom
  always delivers, unlike Windows), but the mission never depends on it — Start →
  `Task Manager` is the guaranteed mouse route, and the dialog’s own `Shut Down` runs
  the real shutdown flow.
- **Login gate.** The inbox window shows a log-on form until `login()` succeeds with
  the password from the note; wrong guesses show an inline alert (Grandma’s hint),
  never a lose state. The gate stays open for the rest of the playthrough.
- **Mission recall.** Reactions overwrite Grandma’s line, so clicking her speech
  bubble puts the current task’s instruction back (the bubble is a real button;
  screen readers get an `sr-only` hint). Start → `Help` shows the same
  instruction in a System Message with the ℹ️ info face and no error ding.
- **Dialogs.** Task screens and the final screen are the same prop-driven WinScreen
  (title, message, icon, and button label come from the current objective); every one
  plays the `win` jingle.
- **Reset.** `Play again` returns to the blank opening (windows closed, no pop-ups)
  and resets the objective index, login, the ad-storm flag, the update dialog, and
  any frozen windows, plus everything the base game already resets. The same reset
  runs mid-game behind Start → `Shut Down...` → `Restart the computer?` — the boot
  line, then the clouds splash — so the player can start over without winning first
  — see [shutdown](./2026-10-20-shutdown-restart.md). The update’s own reboot is the
  opposite: it keeps the whole evening in place.
- **Out of scope.** Level select, saved progress, per-stage desktops (`OBJECTIVES` is
  shaped so distinct scenes can come later), timers, difficulty modes.
