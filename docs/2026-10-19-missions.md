# Missions

Companion spec to [Grandma Tech Support](./2026-10-18-grandma-tech-support.md): the
four-task mission chain that structures a full playthrough.

The game is no longer a single find-the-email vignette. A playthrough is a chain of
four tasks on one desktop: each completion opens a Win95 dialog with `Next task`, and
the fourth opens the final `Computer saved!` screen with `Play again`. The desktop
starts blank and the chain fills it: task 2 springs every browser window back open
with its pop-up chaos, and each storm after that reopens whatever the player closed.
Icon windows, the login, and per-window state persist between tasks.

| #   | Task                  | What the player does                                                                                                                                                                                                                     | Completes on    | Escalation                                                                                        |
| --- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- | ------------------------------------------------------------------------------------------------- |
| 1   | **Log in**            | Sticky Notes says the password is on “the other note”; open `My Documents`, double-click `the_other_note.txt` (Notepad window), launch the Inbox from the Start menu, type `password` into the log-on form                               | `logged-in`     | teaches icon windows, Start-menu launchers, file rows, and the login gate (no pop-ups yet)        |
| 2   | **Find the email**    | the original game’s win, moved to slot two: the whole desktop springs open (Shopping, Virus, Inbox) with the deal, spam, and mailbox-full pop-ups; dismiss `full` with `×`, open the real email from the grandkids among phishing decoys | `email-opened`  | task start opens all three windows and lands `deal` + two `spam` in Shopping, `full` in the Inbox |
| 3   | **Order the toaster** | the first product click tells the joke and starts an ad storm; clear the sale page’s pop-ups with `×` (or shut the window, which takes them along) and click a product again; the other windows’ storms don’t block the order            | `order-placed`  | the storm springs all three windows back open (capped at 5 pop-ups per window)                    |
| 4   | **Save the computer** | grandma clicked something; spam floods every window, liar `Close` buttons keep spawning more. Open the `Virus Shield` desktop icon and run a scan                                                                                        | `scan-complete` | the scan sweeps the whole storm in one motion                                                     |

- **Completion events.** `completeObjective(event)` matches the event against the
  current entry of `OBJECTIVES`. No match means nothing happens, so the shutdown
  joke, decoy clicks, and early scans stay harmless. The wrong click at the wrong
  time is never a lose state.
- **Spring-back.** A task's config can carry `open` (windows that spring open when it
  starts), and every `spawn` entry reopens its target window, so storms always land
  visible, even on a desktop the player tidied up between tasks.
- **Login gate.** The inbox window shows a log-on form until `login()` succeeds with
  the password from the note; wrong guesses show an inline alert (Grandma’s hint),
  never a lose state. The gate stays open for the rest of the playthrough.
- **Dialogs.** Task screens and the final screen are the same prop-driven WinScreen
  (title, message, icon, and button label come from the current objective); every one
  plays the `win` jingle.
- **Reset.** `Play again` returns to the blank opening (windows closed, no pop-ups)
  and resets the objective index, login, and the ad-storm flag, plus everything the
  base game already resets.
- **Out of scope.** Level select, saved progress, per-stage desktops (`OBJECTIVES` is
  shaped so distinct scenes can come later), timers, difficulty modes.
